## 在锁屏时记下进展

几项工作同时进行时，任务清单能提醒我还有什么要做，却很难告诉我上一次停在了哪里。设计 QuadFocus 时，我把记录进展的时机放在按下 Win+L 的那一刻。工作告一段落，刚才的思路也还清楚。

锁屏前，窗口会列出进行中的任务。选中一项，写下这次做完了什么、下一次从哪里开始，再点「保存并锁定」。这条记录会带上时间，留在对应任务的日志里。例如，给「绘制误差曲线」留一句“已画完前两组，下一步核对第三组的单位”，回来时就能直接接着做。

赶着离开可以选「跳过」直接锁屏，临时决定继续工作则选「取消锁屏」。每天第一次解锁时，主看板会自动打开，方便查看当天的安排。

## 四个象限怎样分工

- 主线工作放当前最需要推进的事。例如把「撰写实验报告」拆成「分析结果」和「整理图表」，再给每个阶段添上子任务。
- 支线项目放与主线并行的工作。给绘图工具加一个导出选项，可以在这里单独跟进。
- 有意思的项目用来收下暂时没有交付压力的想法，例如试做一张步行地图。
- 截止期限会按日期汇总前三栏里设了截止日的任务和子任务。没有所属项目的事项也能直接加在这里。

## 拆分、查找与归档

看板支持「项目 → 阶段 → 子任务」三层结构。按 N 选择象限并新建项目，点击任务旁的状态图标可以切换待办、进行中、暂停和完成。工作重心变化时，可以把顶层项目拖到另一个项目象限，也可以在同一父项下调整子任务的顺序。

按 Ctrl+K 可以按标题搜索，找到埋在项目下面的子任务。展开任务的日志，能按时间回看历次进展，也可以直接补记。任务完成后会进入归档，说明、子任务和日志一起保留。要重新启动一个项目，在「归档」里选择「复原」，再选放回哪个项目象限即可。

## 安装与数据备份

本页展示的是仓库主分支的 2.0 界面。下载发布包时，请留意所选版本号。

1. 在 GitHub 发布页选择所需版本，下载并解压 Windows 压缩包。运行环境为 64 位 Windows 10 或 11，并需安装 Microsoft Edge WebView2 运行时。
2. 以管理员身份运行 QuadFocus.exe，以便使用 Win+L 锁屏记录。首次启动时选择数据文件的位置，并按需设置开机自启。
3. 任务、日志和归档都保存在选定的 JSON 文件里。复制这个文件即可备份，也可以把它放在 OneDrive 等同步目录中。
